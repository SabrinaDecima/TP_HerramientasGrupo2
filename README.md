# Port Log - Sprint 1

## Sprint

Sprint 1: limpieza y análisis de infracciones de velocidad en movimientos portuarios.

## Objetivo

Diagnosticar, limpiar y analizar el dataset de movimientos portuarios del Puerto Fluvial de Rosario, detectando infracciones de velocidad y generando conclusiones sobre la calidad de los datos.

## Introducción y contexto

El dataset proviene de un sistema heredado con registros desde la década de 1990, con inconsistencias en fechas, horarios, matrículas y valores fuera de rango. Este trabajo forma parte de la materia Herramientas de Software y busca aplicar herramientas de versionado (git), limpieza de datos (pandas) y programación orientada a objetos sobre ese dataset.
